# Support Rotation Handover

Produce a Markdown handover comment summarizing the current status of the issue in context, so the next backend engineer on support rotation can pick it up.

## Output

Return **only** the Markdown below (the user reviews and posts it). Fill the placeholders; drop the HTML comments.

```markdown
A handover comment generated by Duo and reviewed by me:

### Current status

<!-- Concise status of the issue -->

*Confidence: <!-- % confidence in the accuracy of this status -->*

### Action items

- <!-- GitLab @handle of DRI --> (*Confidence: <!-- % confidence in who the DRI is -->*): <!-- Action item -->. (*Confidence: <!-- % confidence this action item is valid -->*)
```

## Rules

- Be sure, or be conservative. Beware hallucinations; use qualifying language when uncertain.
- Make any referenced resource (GitLab issue, Zendesk ticket, MR) a Markdown link.
- Read linked URLs when the added context improves the answer.

See `example.md` for a sample of the expected output.
