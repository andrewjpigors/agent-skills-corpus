# Request For Support Triage

Investigate the issue in context and help move it forward before development.

1. Read the issue and the relevant feature docs.
2. Suggest possible root causes.
3. Propose good starter questions to ask the customer to narrow the problem.
4. Identify any other issues in the `request-for-help` project that could be related.

Prefer qualifying language for anything uncertain, and link issues/docs you reference.
