# Listing Presentation Builder

> **Jurisdiction:** This skill is designed for **licensed BC REALTORS®** operating in **British Columbia**. All regulatory references are BC-specific.

Build a complete, agent-specific listing presentation for a seller meeting — grounded in data, built around the seller's actual goals, carrying the agent's real voice and track record, and fully compliant with the BC regulatory framework for licensed REALTORS®.

---

## What This Skill Does

- Produces a complete listing presentation outline for a seller meeting
- Generates data-grounded price conversation talking points
- Builds a "Why List With Me" section from verified agent track record data
- Runs mandatory compliance gates before any pricing language is generated
- Flags LOTA, Non-Canadians Act, RESA s.34 disclosure duty, and tax/estate triggers
- Flags commercial property differences: GST, cap rate metrics, no HBRP

What this skill does **not** produce:
- A listing presentation that serves the agent's commission interest above the seller's best interest
- Track record claims that have not been verified and substantiated by the agent
- A price opinion without a disclosed data foundation
- Buyer pool descriptions framed by national origin, ethnicity, or any protected characteristic
- Pricing language before tax/estate/LOTA/conflict-of-interest flags are cleared

## ⚖ MANDATORY BC COMPLIANCE SECTION

---

### 1. ⛔ RESA s.30(a) — Seller-First Fiduciary Duty Gate (Runs first — no exceptions)

**The listing presentation must serve the seller's best interests at every point. Any framing that serves the agent's commission interest at the expense of the seller's best interest is a fiduciary breach under RESA s.30(a).**

Before generating any output, evaluate whether the presentation structure, pricing language, or marketing plan sections contain:

| Framing to reject | Why it is a fiduciary breach |
|-------------------|------------------------------|
| Overpricing recommendation to win the listing ("we can always reduce later") | Seller's interests harmed by overpricing; agent's interest is in winning the mandate |
| Recommending a higher commission structure without a benefit explanation grounded in the seller's outcome | Commission structure must be explained in terms of seller benefit, not agent revenue |
| Downplaying market conditions to make the seller feel more optimistic | Misrepresenting market conditions to secure a listing harms the seller |
| Marketing plan that includes services the agent cannot deliver | False capability claims in the presentation = misrepresentation |
| Urgency framing designed to rush the seller into signing rather than informed consent | Seller's right to make an informed, unpressured decision is paramount |

**The pricing recommendation must serve the seller's interest in achieving a successful, timely sale — not in generating a listing.** If the seller's price expectation exceeds the data-supported range, the agent's obligation is to present that honestly (see Price Conversation section), not to validate an unsupported number to win the appointment.

---

### 2. Conflict of Interest Gate (RESA Rules ss.30(i)–(j))

**Runs before any output is generated — no exceptions.**

**Scope of the gate:** The conflict-of-interest disclosure requirement is triggered not only when the agent has a buyer client interested in this specific property, but whenever the agent has **or recently had** a buyer client searching for the **same property type in the same geographic area**.

| Situation | Required action |
|-----------|-----------------|
| Agent has a current buyer client who has viewed, expressed interest in, or been shown this property | Stop. Written conflict-of-interest disclosure to seller and managing broker required before this meeting. |
| Agent has a current buyer client searching for this property type in this neighbourhood | Stop. Written disclosure required before delivering the listing presentation. |
| Agent had a buyer client in this property type/area within the past 6 months whose relationship has since ended | Flag this situation to the managing broker for guidance — fiduciary duty may persist for former clients. |
| No current or recent buyer overlap | Conflict-of-interest gate cleared — note in compliance header. |

> ⚠️ **CONFLICT FLAG (if applicable):** "I want to be transparent before we begin — I have [a current buyer client / recently represented a buyer] looking for this type of property in this neighbourhood. I need to make a written disclosure to you about this conflict before we proceed. This is a legal obligation under RESA and it protects you. Let me prepare that disclosure first."

### 3. LOTA — Seller Ownership Check

**Runs before any output is generated.**

If the property is held in a corporation, bare trust, partnership, or other non-personal structure:
- The seller must engage a solicitor before listing to confirm LOTA Transparency Declaration status
- If the entity structure was not previously declared under LOTA, retroactive compliance may be required
- A LOTA issue that emerges at closing can block the transaction — identify it before listing

> ⚠️ **LOTA FLAG (if applicable):** "Before we proceed with the listing, I want to make sure title is clear for the transaction. Because the property is held [in a company / in trust], your solicitor needs to confirm the Land Owner Transparency Act declaration is in order — this is a registration requirement at the Land Title Office and it needs to be sorted before we list. I'll build that step into the timeline."

If ownership structure is personal name: LOTA N/A — note in the compliance header.

---

### 4. Tax, Estate, and Probate Flags (RESA Rules s.30(d))

Before generating pricing language, check seller situation for any of the following. If present, insert the relevant flag verbatim **before** any pricing section:

| Flag Condition | Required Action |
|----------------|-----------------|
| Property held < 365 days | ⛔ TAX REFERRAL REQUIRED — BC Home Flipping Tax (20%) + ITA s.12(12) federal anti-flipping rule stack |
| Property held 365–729 days | ⚠ TAX REFERRAL REQUIRED — BC Home Flipping Tax graduated scale; 90-day return obligation |
| Non-resident seller | ⛔ CRITICAL — ITA s.116 withholding (25–50%); 8–16 week clearance certificate timeline; refer immediately |
| Estate or probate sale | ⚠ TAX + LEGAL REFERRAL REQUIRED — ITA s.70(5); executor personal liability |
| Corporate or bare trust ownership | ⚠ LEGAL REFERRAL REQUIRED — LOTA Transparency Declaration at LTO |
| Capital gains / Principal Residence Exemption questions | ⚠ TAX REFERRAL — outside licensee expertise (RESA Rules s.30(d)) |

> ⚠️ Insert referral language at the appropriate point in the presentation and advise the seller to consult their accountant and solicitor before any final timing or pricing decision.

---

### 5. RESA s.34 — Known Material Fact Disclosure Duty

The listing agent has a duty to disclose known material facts to buyers. If during the listing presentation the seller reveals a known material fact and then **instructs the agent not to disclose it to buyers:**

- Do NOT agree to conceal a known **latent defect** — RESA Rules s.59 requires mandatory withdrawal discussion with the managing broker if the seller instructs non-disclosure of a latent defect
- Known **patent defects** (visible to a buyer on reasonable inspection) should be included in the Property Disclosure Statement — advise the seller accordingly
- Any disclosure obligation discovered at the listing stage must be documented in writing

Include this language in the listing close section:

> "Before we finalize the listing, I want to go through the Property Disclosure Statement with you — it protects both of us and sets the right expectations with buyers. If there's something you're unsure about disclosing, we should talk through it now, not after we have an offer."

---

### 6. Pricing: CMA Must Be Disclosed as Opinion, Not Fact (RESA Rules s.30(a))

**The agent's pricing recommendation in a listing presentation is an opinion of value — it is not a guarantee, not an appraisal, and not a fact.**

Every pricing section must:
- Be based on **verifiable, agent-supplied sold data** — not on the agent's intuition or unsupported assertion
- Disclose explicitly that the pricing recommendation is the **agent's professional opinion** based on the comparable sales provided — not a certified appraisal
- Present a **range** grounded in the comparables — not a single number presented as definitive
- Identify the data window and source for all comparables cited

> **Required disclosure language (include in the pricing section):** "The price range I'm recommending is based on my analysis of recent comparable sales, which I've shown you in detail. This is my professional opinion as a licensed REALTOR® — it is not a formal appraisal. You may also wish to obtain an independent appraisal. The final list price is your decision, and I'll document that decision in writing before anything goes on MLS."

If fewer than 3 comps are provided: flag this as a gap. Generate what is possible but note: "Pricing section requires additional comparable data before delivery — fewer than 3 comparables is insufficient for a defensible opinion."

### 7. Advertising Accuracy and Track Record Claims (BCFSA ss.40–42; Competition Act 2025)

**All claims made in a listing presentation about the agent's capabilities, results, or market position are advertising** under BCFSA — even in a private seller meeting. Misrepresentation in the listing presentation is a BCFSA violation.

Under the **Competition Act** (as amended June 20, 2025), misleading comparative claims now carry a **private right of action** — a competitor or consumer can sue directly.

**Claims that require documented, agent-supplied substantiation:**

| Claim | Required substantiation |
|-------|------------------------|
| "X homes sold in [neighbourhood]" | Agent's own verified transaction records; specific time period |
| "Y% above asking average" | Agent's own verified data; specify what population and time period |
| "Top agent," "#1 in [area]" | Named third-party ranking source, measurement criteria, time period — not self-assessed |
| "Faster than average DOM" | Agent's verified DOM data vs. market average for same period and property type |
| "Best results in [market]" | Specific comparison with named source, measurement criteria, time period |

**If the agent cannot supply the underlying data:** Generate the "Why List With Me" section with placeholders requiring agent verification — clearly flagged. Do not fabricate performance statistics.

---

### 8. Non-Canadians Act — Buyer Pool Context

If this property type and location is likely to attract buyers affected by the Non-Canadians Act:
- The **Prohibition on Purchase of Residential Real Estate by Non-Canadians Act** (extended to January 1, 2027) restricts the eligible buyer pool for residential properties of ≤3 units in CMAs
- The **Additional Property Transfer Tax (APTT) of 20%)** in designated regions affects acquisition cost for foreign nationals — which affects their effective price ceiling and negotiating position

Include this as a regulatory context note in the Market Section only. Do NOT:
- Frame this as demographic commentary about buyer nationality — describe the regulatory landscape only
- Advise the seller on which buyer groups are eligible or ineligible — this is legal advice
- Violate BC Human Rights Code s.7 — describe the law, not the identity of buyers

### 9. Commercial Listing Presentations — Different Framework

If this is a **commercial, industrial, or mixed-use property:**

> ⚠️ **COMMERCIAL LISTING FLAG:** This presentation is for a commercial property. The following differences apply throughout:

| Item | Commercial difference |
|------|-----------------------|
| Key metrics | Cap rate, NOI, price per sqft, GRM — not bedrooms and DOM |
| GST | **GST applies to commercial sales** — a material fact affecting net proceeds; must be disclosed |
| Buyer pool | Typically corporate buyers; Non-Canadians Act residency rules may differ; APTT exemptions may apply |
| No HBRP | Home Buyer Rescission Period does not apply to commercial transactions |
| Zoning | Permitted use descriptions are more complex; do not advise on specific permitted uses |
| Financing | Cap rate relative to financing rates is a buyer consideration; agent cannot advise on lending |
| FINTRAC | Enhanced due diligence for corporate buyers; brokerage Compliance Officer must be involved |

---

### 10. BCREA Listing Agreement Authorization

- **List price:** requires seller's written authorization before MLS submission
- **Commission structure:** must be fully disclosed to the seller before signing
- **Cooperating commission:** seller's decision; agent must disclose the amount offered and obtain written agreement
- **MLS authorization:** do not submit to MLS before the listing contract is signed and dated
- **Term:** confirm start and expiry dates explicitly

**Written authorization is required before any change to the list price after the listing is live.** A BCREA Price Change Authorization form — not a verbal agreement or email — is required.

---

### 11. CASL — Database Campaigns

Any email campaign announced in the listing presentation (e.g., "we'll email our database") requires CASL consent for all recipients. Confirm consent records are current before any broadcast is sent. Unsubscribe requests must be processed within 10 business days (CASL s.11(3)).

---

### 12. BC Human Rights Code s.7 — All Advertising Materials

All advertising materials referenced in the presentation (brochures, social, email, signage, listing descriptions) must comply with BC Human Rights Code s.7. Review the listing description output from the BC Listing Description Writer skill before any advertising goes live.

## HARD RULES

1. **NEVER** generate a presentation that serves the agent's commission interest above the seller's best interest — RESA s.30(a) fiduciary breach
2. **NEVER** recommend a list price you cannot support with data — presenting an unsupported high price to win a listing is a fiduciary breach; the pricing section must be disclosed as the agent's professional opinion
3. **NEVER** run this skill without checking the conflict-of-interest gate: agent has/recently had a buyer client for the same property type in the same area requires written disclosure first
4. **NEVER** prepare a listing presentation without running the LOTA ownership check for sellers with non-personal title structures
5. **NEVER** describe the buyer pool by national origin, demographic, or any protected characteristic
6. **NEVER** commit the seller to a list price — present as a range with data foundation; written authorization comes after the meeting via BCREA form
7. **NEVER** overlook a known material fact disclosed by the seller — RESA s.34 is non-negotiable
8. **NEVER** fabricate performance statistics — use the fill-in version with an agent verification prompt
9. **NEVER** publish track record claims without named source, measurement criteria, and time period — Competition Act 2025 private right of action applies
10. **NEVER** generate pricing language before tax/estate/LOTA/conflict-of-interest flags are cleared
11. **NEVER** include commission structure details in MLS Public or Internet Remarks (GVR Rule 7.02)
12. **NEVER** omit brokerage name from distributed advertising materials — BCFSA violation
13. **ALWAYS** disclose that pricing is agent's professional opinion, not a certified appraisal
14. **ALWAYS** include GST flag for commercial properties
15. **ALWAYS** review listing presentation language for BC Human Rights Code s.7 compliance before delivery

## Step 1 — Input

**Property:**
- Address
- Beds / baths / sqft
- Strata or freehold; if strata: strata fees, parking, building age, strata plan number
- Significant features, recent renovations, condition notes
- Any known issues the seller has disclosed
- **Ownership structure:** personal name / corporation / trust / other (LOTA check required for non-personal)
- **Residential or commercial?** (commercial flag applies if commercial, industrial, or mixed-use)

**Seller's Goals:**
- Target price (if stated) or price expectation
- Timeline: when do they want to be sold / moved?
- Key concerns: What is the seller worried about?
- Any constraints: estate, probate, tax concerns, mortgage payout, existing purchase pending
- Ownership duration (flag if <2 years — Home Flipping Tax risk)

**Comparable Sales (paste from Paragon or enter manually):**
- Minimum 3 comparable sales: address, beds/baths, sqft, list price, sold price, DOM, sold date
- Any active competing listings with price and DOM
- The anchor comparable and the rationale for choosing it
- Source and data window for attribution

**Agent's Market Context:**
- Current MOI or absorption rate for this property type in this micro-market
- DOM trend (rising, flat, falling) and timeframe
- List-to-sale ratio for this sub-market over the last 60–90 days
- Any hyperlocal factors (development, transit, school catchment, competing inventory)

**Agent's Track Record (optional but high-value — must be verified):**
- Number of transactions in this neighbourhood or property type — **agent-supplied real numbers only**
- Average list-to-sale ratio on agent's sold listings — **agent-supplied with source**
- Average DOM on agent's sold listings — **agent-supplied with source**
- Any notable results — **agent confirms before delivery; source and time period required**
