Initialize a new project with Claude Code configuration. Interactive wizard.

## 1. Gather Project Info
Ask about:
- Language (Python, TypeScript, Rust, Go, other)
- Framework (FastAPI, React, Next.js, Express, etc.)
- Project type (API, CLI, library, web app, data pipeline, ML)
- Package manager, testing framework, database, deployment

## 2. Generate CLAUDE.md
Create a project-specific CLAUDE.md with: Project Overview, Tech Stack, Quick Start commands, Commands table, Project Structure, Coding Standards, Testing patterns.

## 3. Suggest Configuration
Recommend relevant instruction files, skills, and hooks from the toolkit based on the project type.

## 4. Output Setup Commands
Generate copy-pasteable commands to install instruction files, skills, and hooks. Reference the install script if available.

## 5. Optional Extras
Offer: GitHub Actions workflow, Dockerfile, pyproject.toml/tsconfig.json templates.
