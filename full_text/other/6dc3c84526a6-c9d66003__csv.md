# CSV

Use this skill for local `.csv` work only.

## Start here

1. For new files, write a JSON spec and run `scripts/csv_tool.py create`.
2. If changing an existing CSV, inspect first.
3. Use `R<row>C<col>` coordinates for edits.
4. Save to a new output path unless the user explicitly wants replacement.

## Commands

```bash
python3 agent/skills/csv/scripts/csv_tool.py inspect input.csv
python3 agent/skills/csv/scripts/csv_tool.py create spec.json output.csv
python3 agent/skills/csv/scripts/csv_tool.py edit input.csv edits.json output.csv
```

## Recommended workflow

- Use `rows` for creation.
- Use `delimiter` only when the user needs something other than a comma.
- Inspect before editing so row and column positions are unambiguous.
