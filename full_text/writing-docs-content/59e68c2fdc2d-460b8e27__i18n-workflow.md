# I18n Workflow

Use when text reaches users or operators.

## Workflow

1. Locate the repo's canonical locale/message source.
2. Add or update the source-language entry.
3. Run the repo's translation or message sync command.
4. Verify the UI renders the translated string and handles long text.
5. For legal, compliance, or policy copy, use approved source text. Do not invent
   wording.

Report changed message keys and sync command.
