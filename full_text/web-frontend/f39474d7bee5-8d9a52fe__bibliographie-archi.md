# `bibliographie-archi` : citer et organiser ses sources

## Vue d'ensemble

Citer ses sources est un réflexe à acquérir dès la L1. Ça :
- évite le plagiat (sanctionné),
- crédibilise un rendu,
- permet à un lecteur de retrouver l'origine.

## Outils

### Zotero
Outil gratuit, open source. Recommandé.
- Téléchargement : https://www.zotero.org/
- Plug-in navigateur pour capter une référence depuis le web en 1 clic.
- Plug-in Word / LibreOffice / Google Docs pour insérer une référence dans un texte.
- Style de citation : choisir un style cohérent (voir plus bas).

### Mendeley, EndNote
Existent mais Zotero est généralement préféré en France (gratuit, indépendant).

## Style de citation

Plusieurs normes existent. En France pour les ENSA :
- **ISO 690** : norme française officielle.
- **APA** (American Psychological Association) : très répandu, simple.
- **Chicago** : utilisé en histoire de l'art.

Choisir UN style, le tenir tout au long du document.

## Format des références (style ISO 690 simplifié)

### Livre

```
NOM Prénom, *Titre du livre*, Lieu, Éditeur, année, nombre de pages.
```

Exemple :
```
LE CORBUSIER, *Vers une architecture*, Paris, Flammarion, 1995 (1ère éd. 1923), 251 p.
```

### Chapitre dans un ouvrage collectif

```
NOM Prénom, "Titre du chapitre", in NOM Prénom (dir.), *Titre du livre*, Lieu, Éditeur, année, pages.
```

### Article de revue

```
NOM Prénom, "Titre de l'article", *Nom de la revue*, n° X, mois année, pages.
```

Exemple :
```
LACATON Anne, VASSAL Jean-Philippe, "Pas de démolition", *AMC*, n° 308, mars 2022, p. 60-72.
```

### Site web

```
NOM Prénom, "Titre", *Nom du site*, date de publication, [en ligne], URL, consulté le date.
```

### Projet d'architecture

```
NOM(S) Prénom(s) (architecte(s)), *Nom du projet*, Lieu, année de livraison.
```

## Citation dans le texte

Deux usages :
- **Citation courte** (< 3 lignes) : entre guillemets dans le texte. "Une maison est une machine à habiter."
- **Citation longue** (> 3 lignes) : sur un paragraphe à part, en retrait.

Toujours indiquer la **source** entre parenthèses ou en note de bas de page.

## Bibliographie finale

À la fin du document, lister **toutes les sources** utilisées, par ordre alphabétique d'auteur.

Séparer éventuellement en sections :
- ouvrages,
- articles,
- sites web,
- projets cités.

## Iconographie

Les **images** ont aussi des sources. À chaque image inclure :
- auteur (photographe, dessinateur, architecte),
- année,
- source.

Exemple : `Image : Hisao Suzuki, Maison Bordeaux, 1998, OMA archives.`

## Plagiat

- Recopier un texte sans citer = **plagiat**, sanction possible (note nulle, voire exclusion).
- Reformuler une idée d'un auteur sans le citer = **plagiat aussi**.
- Citer ses sources **valorise** un travail, ce n'est pas un aveu de faiblesse.

## Procédure

1. **Identifier la source** : livre, article, projet, image ?
2. **Donner le format** exact pour cette source.
3. **Conseiller un style** si l'utilisateur n'en a pas choisi.
4. **Renvoyer vers Zotero** pour la gestion long terme.

## Notes pédagogiques

- Importer **tout** dans Zotero dès qu'on lit : on ne sait jamais ce qui resservira.
- Annoter dans Zotero avec **tags** ("structure", "lumière", "logement") pour retrouver.
- Faire des **dossiers Zotero par projet** ou par cours.

## Limites

- Le skill aide à formater, il ne fait pas le travail de Zotero.
- Les conventions varient selon les enseignants : demander avant le premier rendu écrit.
