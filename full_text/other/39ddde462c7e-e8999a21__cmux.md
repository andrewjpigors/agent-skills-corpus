# cmux Core Control

cmux is open-source (manaflow-ai/cmux, GPL-3.0) — a Ghostty-based macOS terminal where AI coding agents are first-class citizens. Every window/workspace/pane/surface is addressable from the CLI, and text I/O works across surfaces. That's the unique value: my Bash tool runs in *one* surface, but `cmux send` reaches *any* surface.

## Mental model

```
window      ← top-level macOS window
└── workspace   ← tab-like group inside the window (sidebar entry)
    └── pane       ← split container inside a workspace
        └── surface    ← a tab inside a pane (terminal OR browser)
```

Handles use short refs by default: `window:1`, `workspace:2`, `pane:3`, `surface:4`. UUIDs work too. Indexes are accepted but ambiguous — **always pass `surface:N` form when the index could collide with the Nth-of-type ordering** (see Gotchas).

## Fast start

```bash
# Where am I?
cmux identify --json

# Full topology in one shot
cmux tree --all

# List specific levels
cmux list-windows
cmux list-workspaces
cmux list-panes               --workspace workspace:1
cmux list-pane-surfaces       --pane pane:1

# Find a workspace by name; --content also greps terminal contents
cmux find-window "视频号"
cmux find-window --content "ERROR" --select
```

## Cross-surface terminal I/O (the killer feature)

```bash
# Read another surface's screen (visible viewport)
cmux read-screen --surface surface:8

# Read with scrollback — last 200 lines
cmux read-screen --surface surface:8 --scrollback --lines 200

# Send text to another terminal (\n sends Enter, \t sends Tab)
cmux send --surface surface:8 "git status\n"

# Send a single key (arrow, ctrl-c, etc.)
cmux send-key --surface surface:8 "C-c"
cmux send-key --surface surface:8 "Up"

# tmux-compatible alias for read-screen
cmux capture-pane --surface surface:8 --scrollback --lines 200
```

Use this to drive a sibling Claude/Codex session, watch a long-running build, or feed input to an interactive REPL the user has open.

## Topology mutation

```bash
# New empty workspace, optionally pre-populated
cmux new-workspace --name "review" --cwd ~/Projects/foo --command "rg TODO"

# Split the current pane to the right
cmux new-split right

# New surface (terminal or browser) in the current pane
cmux new-surface --type terminal
cmux new-surface --type browser --url https://example.com

# Move a surface to another pane
cmux move-surface --surface surface:7 --pane pane:2 --focus true

# Reorder within a pane
cmux reorder-surface --surface surface:7 --before surface:3

# Close
cmux close-surface --surface surface:7
cmux close-workspace --workspace workspace:3
```

## Focus & attention

```bash
cmux focus-window --window window:1
cmux focus-pane   --pane pane:2
cmux select-workspace --workspace workspace:2

# Visual cue on another surface (blue ring + sidebar light)
cmux trigger-flash --surface surface:8

# Native macOS notification tied to a surface
cmux notify --surface surface:8 --title "Build done" --body "All tests passed"
```

## Identify yourself before acting

When invoked from inside a cmux terminal, the env vars `CMUX_WORKSPACE_ID` and `CMUX_SURFACE_ID` are set automatically — most commands default to those. To confirm before doing anything destructive:

```bash
cmux identify --json
# → {"workspace_id":"workspace:1","surface_id":"surface:13","caller":...}
```

Without this you may move/close the wrong surface.

## Output format

```bash
# Default: short refs (workspace:1, surface:13)
cmux list-workspaces

# Include UUIDs when you need to persist a stable ID
cmux list-workspaces --id-format both
cmux list-workspaces --id-format uuids

# JSON output for scripting (most commands accept it)
cmux --json list-workspaces
cmux --json identify
```

## Gotchas (learned the hard way)

1. **`--surface 3` is ambiguous.** Plain integers can be parsed as the *Nth browser surface* in some commands rather than `surface:3`. Always pass the full ref form: `--surface surface:3`. (Source: `~/.claude/projects/-Users-pallasting/memory/feedback_tool_strategy.md`.)
2. **`cmux tree --all` first**, every time the layout might have changed. Surface IDs renumber when surfaces close. Re-read before sending text to a remote surface.
3. **`CMUX_SURFACE_ID` defaults are usually right** when you want to act on yourself, but always pass `--surface` explicitly when targeting another surface.
4. **`refresh-surfaces`** if a surface looks stale or `surface-health` reports issues.

## Escape hatch: raw RPC

cmux exposes 130+ RPC methods. The CLI covers most, but for anything missing:

```bash
cmux capabilities                       # List all RPC methods
cmux rpc browser.cookies.get '{"workspace_id":"...","surface_id":"..."}'
cmux rpc surface.report_tty '{"workspace_id":"...","surface_id":"...","tty_name":"ttys001"}'
```

## Companions

- `cmux-browser` — automate browser surfaces (snapshot, click, fill, wait)
- `cmux-markdown` — open a markdown file as a live-reload rendered panel
- `cmux-agents` — spawn parallel Claude Code teammates, drive sibling agents, post attention alerts
