# Review Config

Use first-principles review for AI config.

## Questions

- Does this prevent a real defect, repeated correction, or wasted agent effort?
- Is it personal, workspace-local, or team-shareable?
- Does it belong in always-on rules, scoped rules, a skill, an agent, a script, or
  local notes?
- Does it duplicate or contradict existing guidance?
- Is it too vague to trigger reliably?
- Does it contain old workplace identifiers, secrets, paths, or repo-specific
  details?
- Can a script or quality gate enforce it better than text?

Output findings ordered by severity with suggested action.
