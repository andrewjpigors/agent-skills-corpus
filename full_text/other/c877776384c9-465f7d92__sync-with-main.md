# Sync With Main

Use once workspace's branch update convention is known.

## Workflow

1. Confirm current branch is not the default branch.
2. Check for dirty work and stash only with explicit intent.
3. Fetch the default remote branch.
4. Use the workspace convention: rebase, merge, or recreate branch. Do not assume.
5. Resolve conflicts by preserving current task intent and upstream behavior.
6. Run relevant quality gates.
7. Do not push or force-push without explicit confirmation.

Always use `--force-with-lease` instead of `--force` when a force push is
explicitly approved.
