# Testing Standards

## Framework: pytest

### Structure
- Unit tests: `tests/test_*.py` — test individual functions and classes
- E2E tests: `tests/e2e/test_*.py` — test full user flows with Playwright
- Shared fixtures: `tests/conftest.py` — reusable test setup

### Naming
- Test files: `test_<module>.py` matching the source file they test
- Test functions: `test_<behavior>_<expected_result>` — describe the scenario
- Fixtures: noun phrases describing what they provide (`client`, `sample_product`, `auth_headers`)

### Flask Test Patterns
```python
# Use Flask test client via fixture
def test_homepage_returns_200(client):
    response = client.get("/index.html")
    assert response.status_code == 200
    assert b"Parts Portal" in response.data

# Test POST routes with data
def test_add_to_cart_creates_session(client):
    response = client.post("/add_to_cart.html", data={"product_id": "1"})
    assert response.status_code in (200, 302)
```

### Assertions
- Assert specific values: `assert response.status_code == 200` not `assert response.status_code`
- Use `in` for content checks: `assert b"expected text" in response.data`
- One logical assertion per test — multiple asserts OK if testing the same behavior

### Test Data
- Use fixtures for reusable test data, not global variables
- Keep test data minimal — only what's needed for the assertion
- Never rely on database state from other tests (tests must be independent)

### Running Tests
```bash
ruff check .                     # Lint check (run before tests)
pytest tests/                    # All unit tests
pytest tests/e2e/               # E2E tests (requires Playwright)
pytest tests/ -v                 # Verbose output
pytest tests/ -k "test_product" # Run matching tests only
pytest tests/ --tb=short        # Short tracebacks
```

### CI Integration
- Tests run in the `test` stage before deploy
- E2E tests may need browser dependencies (`playwright install`)
- Test results in JUnit XML: `pytest --junitxml=tests/results.xml`
- Non-zero exit code blocks pipeline progression
