# `redaction-rendu` : écrire pour l'architecture

## Vue d'ensemble

En L1, on écrit moins qu'en lettres mais on écrit quand même : texte d'intention sur une planche, notice descriptive d'un projet, court mémoire d'analyse. Ce skill aide à bien le faire.

## Types de textes

### Texte d'intention (planche)

- **Très court** : 4 à 8 lignes.
- Sur la planche, en complément des dessins.
- Énonce le **parti pris** et les **décisions principales**.
- Pas de description, pas de chronologie.

### Notice descriptive

- **1 à 2 pages**.
- Pour un dossier remis au jury.
- Sections classiques : contexte, parti, plan, matérialité, structure.
- Plus factuel que le texte d'intention.

### Court mémoire d'analyse

- **5 à 15 pages**.
- Étude d'une référence ou d'une thématique.
- Structure type :
  1. Introduction (problématique, méthode)
  2. Présentation du cas
  3. Analyse (selon plan choisi)
  4. Discussion / interprétation
  5. Conclusion
  6. Bibliographie

## Principes d'écriture

### Une phrase = une idée

Phrase longue = mauvais. Diviser, simplifier.

### Vocabulaire précis

Utiliser les bons mots techniques (voir `lexique-archi-fr`). Mais ne pas faire jargonner : si "porteur" suffit, ne pas écrire "élément vertical assurant la transmission des charges descendantes".

### Pas d'auto-célébration

- "Mon magnifique projet" : non.
- "Je propose un projet" : ok.
- "Le projet propose" : encore mieux (recul).

### Pas d'auto-flagellation

- "J'ai pas eu le temps de finir le détail" : à ne pas écrire.
- "Le détail technique reste à approfondir" : si nécessaire.

### Vocabulaire à mobiliser

- **Implanter** : poser le projet sur le terrain
- **Composer** : organiser visuellement
- **Articuler** : créer un lien entre éléments
- **Cadrer** : cadrer une vue, une lumière
- **Hiérarchiser** : organiser par importance
- **Inscrire** : poser dans un contexte
- **Décliner** : varier autour d'un thème
- **Affirmer** : poser comme une décision claire

### Mots à éviter (souvent creux)

- "joli", "beau", "agréable" (subjectifs)
- "moderne" sans contexte (ça veut dire quoi ?)
- "respectueux du site" (formule générique sans contenu)
- "fonctionnel" (tout projet l'est, sinon il ne tient pas debout)

## Modèle de texte d'intention (planche)

```
[Titre du projet en gras]

[Une phrase qui énonce le parti, en une formule]

[2 à 3 phrases qui développent : ce que le projet fait, comment il
le fait, ce qu'il refuse de faire. Ne pas décrire, raconter une
décision.]

[Optionnel : 1 phrase finale qui ouvre vers l'usage, la matière, le
temps long.]
```

Exemple :

```
**Pli**

Le projet plie le sol pour faire abri.
Au lieu de poser un volume sur le terrain, je creuse, je redresse,
j'enroule une bande de terre. La maison naît du sol et y retourne
par la toiture-prairie.
Habiter ici, c'est habiter une géographie.
```

## Procédure

1. **Identifier le type de texte** à produire.
2. **Demander la matière** : projet, parti, contexte.
3. **Proposer une structure**, pas un texte tout fait.
4. **Reformuler** ce que l'étudiante propose pour la rendre plus juste, sans changer son intention.
5. **Vérifier le ton** : ni grandiloquent, ni auto-déprécié.

## Notes pédagogiques

- **Lire à voix haute** : si ça sonne faux, c'est mal écrit.
- **Faire relire** par quelqu'un qui n'est pas archi : si la phrase clé n'est pas comprise, retravailler.
- **Économiser les mots** : un texte d'intention de 6 lignes vaut souvent mieux qu'un de 20.

## Limites

- Le skill n'écrit pas le texte à la place de l'étudiante, c'est son projet qui parle.
- Le ton varie selon l'école et l'enseignant : adapter.
