# Slack Message

Use to draft concise team communication.

## Rules

- Never post without explicit confirmation.
- Do not include secrets, token fragments, private logs, or large code dumps.
- Link to canonical artifacts instead of pasting long context.
- Keep tone direct and action-oriented.

## Format

- Context: one sentence.
- Ask/update: one or two bullets.
- Needed action or decision: explicit when relevant.
