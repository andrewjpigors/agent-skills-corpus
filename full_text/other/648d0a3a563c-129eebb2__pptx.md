# PPTX

Use this skill for local `.pptx` work only.

## Setup

```bash
python3 -m pip install --break-system-packages -r "${PI_CODING_AGENT_DIR:-${HOME}/.pi/agent}/skills/pptx/requirements.txt"
```

## Start here

1. For new decks, write a JSON spec and run `scripts/pptx_tool.py create`.
2. For changes to an existing deck, inspect first.
3. Use the returned `sid:<slide_id>` and `sid:<slide_id>/shid:<shape_id>` identifiers for edits.
4. Save to a new output path unless the user clearly wants replacement.

## Commands

```bash
python3 agent/skills/pptx/scripts/pptx_tool.py inspect input.pptx
python3 agent/skills/pptx/scripts/pptx_tool.py create spec.json output.pptx
python3 agent/skills/pptx/scripts/pptx_tool.py create spec.json output.pptx --template template.pptx
python3 agent/skills/pptx/scripts/pptx_tool.py edit input.pptx edits.json output.pptx
python3 agent/skills/pptx/scripts/pptx_tool.py review input.pptx review.json output.pptx
```

## Recommended workflow

### Create

- Use a deck `title` plus a `slides` array.
- Each slide can provide `title`, `content`, `image_path` or `image_url`, `image_position`, and `image_size`.
- Keep body content as a list of short lines rather than one long paragraph.

### Inspect before editing

`inspect` returns:

- Slide IDs like `sid:256`
- Shape IDs like `sid:256/shid:4`

Use those IDs exactly in the edit spec.

### Edit

Supported structural ops mirror the source code split:

- insert a slide before or after another slide
- delete a slide
- update an existing shape's text
- fill newly inserted slide `title` and `body` slots with `n1:slot:title` or `n1:slot:body`

### Review

Review notes are added as visible textboxes on the slide, not native PowerPoint comment bubbles. That keeps the skill local and predictable.
