# `recherche-iconographique` : trouver des images de qualité

## Vue d'ensemble

Les rendus d'analyse, mémoires, planches de référence demandent des images : plans originaux, photos d'auteur, croquis. Quelques bonnes adresses, quelques règles de droit.

## Bases de données spécialisées (gratuites)

### Pour les projets contemporains

- **ArchDaily** : https://www.archdaily.com/ (multilingue, gigantesque)
- **Divisare** : https://divisare.com/ (très qualitatif, design soigné)
- **Dezeen** : https://www.dezeen.com/ (design + archi)
- **Domus** : https://www.domusweb.it/
- **AMC** : https://www.amc-archi.com/ (français)
- **Architectures Contemporaines** (DRAC) : pour la France

### Pour les projets historiques

- **Cité de l'architecture et du patrimoine** : photothèque en ligne
- **Gallica** (BnF) : https://gallica.bnf.fr/ (livres, plans anciens libres de droits)
- **Wikipedia / Wikimedia Commons** : https://commons.wikimedia.org/ (souvent libre de droits)
- **Mémoire** : portail patrimoine ministère Culture
- **POP** (Plateforme Ouverte du Patrimoine) : https://www.pop.culture.gouv.fr/

### Pour les plans originaux

- **Site officiel de l'agence** : souvent les meilleurs plans (Lacaton & Vassal, OMA, etc.)
- **Monographies** en bibliothèque ENSAPL : scans personnels possibles pour usage scolaire
- **2G**, **El Croquis**, **A+U** : revues monographiques, scans en bibliothèque

### Pour le site et le contexte

- **Géoportail** (IGN) : photos aériennes, anciennes orthos
- **Google Street View** : pour les vues depuis la rue
- **Mapillary** : alternative ouverte

## Droits d'auteur

### Principe

En France, une oeuvre est protégée pendant **70 ans après la mort de l'auteur**. Avant, droits d'auteur = consentement et souvent paiement.

### Pour un usage **pédagogique**

L'exception pédagogique autorise l'usage d'oeuvres pour un rendu interne à l'école, sans rémunération, à condition de **citer la source**.

### Pour une **publication** (site web, réseaux sociaux, mémoire publié)

Il faut :
- soit une oeuvre **libre de droits** (Creative Commons, domaine public),
- soit l'**autorisation écrite** de l'auteur.

### Creative Commons

Licences qui autorisent l'usage sous conditions :
- **CC0** : domaine public, tout est permis.
- **CC BY** : citer l'auteur.
- **CC BY-NC** : citer, pas d'usage commercial.
- **CC BY-NC-SA** : citer, pas commercial, partage à l'identique.
- **CC BY-ND** : citer, pas de modification.

Wikimedia Commons utilise principalement CC BY-SA. Toujours **vérifier la licence** avant usage.

## Qualité des images

- Pour un **rendu A1**, viser au moins **2000 px de large** par image.
- **Format** : JPEG ou PNG pour photos. SVG ou PDF pour vecteurs.
- **DPI** : 150 dpi à l'échelle d'impression minimum.
- Une image qui pixellise sur la planche est **rédhibitoire**.

## Procédure

1. **Identifier ce que l'utilisateur cherche** : plan d'un bâtiment connu ? photo d'une référence ? image de site ?
2. **Recommander la ou les sources** adaptées.
3. **Vérifier la qualité** (résolution suffisante).
4. **Rappeler les droits** : pour un rendu interne, citation OK. Pour publication, attention licences.

## Sortie attendue

```
Tu cherches des images de la Villa Savoye pour un dossier d'analyse :

Sources recommandées
1. Fondation Le Corbusier : https://www.fondationlecorbusier.fr/
   plans originaux, photos d'archives, droits réservés mais usage pédagogique OK
2. Wikimedia Commons : photos modernes libres de droits CC BY-SA
3. ArchDaily : article complet avec plans redessinés
4. Monographie *Le Corbusier, oeuvre complète* (Boesiger),
   à la bibliothèque ENSAPL

Légende type
"Plan du rez-de-chaussée, Villa Savoye, Le Corbusier (1928-1931).
Source : Fondation Le Corbusier, FLC 19425."
```

## Notes pédagogiques

- Une **image non créditée** dans un rendu peut faire perdre des points.
- **Ne jamais télécharger** un plan vu sur Pinterest sans vérifier la source d'origine.
- En cas de doute sur la source : ne pas utiliser.

## Limites

- Certains plans (Aalto, Mies) ne sont pas en libre accès, il faut aller en bibliothèque.
- Le skill ne télécharge pas les images, il oriente vers les bonnes sources.
