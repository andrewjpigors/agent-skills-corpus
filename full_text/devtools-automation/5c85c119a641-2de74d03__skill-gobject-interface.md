# Skill: GObject Interface Generator

Generates complete GInterface boilerplate including the interface header (with vtable struct), default_init implementation, public wrapper functions, and example concrete implementation. All output follows gnu89 C conventions with `/* */` comments and TAB indentation.

## When to Use

- When creating a new GInterface for polymorphic dispatch
- When defining a contract that multiple GObject types should implement
- When the user says "create an interface", "add an interface", or "define a vtable"
- When designing plugin or module systems with swappable implementations

## Instructions

### 1. Gather Requirements

Ask the user (or infer from context):

| Parameter | Required | Default | Description |
|-----------|----------|---------|-------------|
| **Project prefix** | Yes | — | Namespace prefix (e.g., `BACON`, `LC`, `GST`) |
| **Interface name** | Yes | — | PascalCase name (e.g., `BaconExecutable`, `LcChannel`) |
| **Prerequisite type** | No | `GObject` | Required parent type for implementors |
| **Virtual methods** | Yes | — | List of vfuncs with signatures |
| **Signals** | No | none | Signals defined on the interface |
| **Include guard style** | No | `#ifndef` | `#ifndef` or `#pragma once` |

### 2. Derive Naming

```
Project prefix:    BACON
Interface name:    BaconExecutable
lowercase:         bacon_executable
UPPERCASE:         BACON_EXECUTABLE
get_type:          bacon_executable_get_type
TYPE macro:        BACON_TYPE_EXECUTABLE
IS macro:          BACON_IS_EXECUTABLE (auto-generated by G_DECLARE_INTERFACE)
GET_IFACE macro:   BACON_EXECUTABLE_GET_IFACE (auto-generated)
```

### 3. Generate Interface Header

```c
#ifndef BACON_EXECUTABLE_H
#define BACON_EXECUTABLE_H

#if !defined(BACON_INSIDE) && !defined(BACON_COMPILATION)
#error "Only <bacon.h> can be included directly."
#endif

#include <glib-object.h>
#include <gio/gio.h>

G_BEGIN_DECLS

#define BACON_TYPE_EXECUTABLE (bacon_executable_get_type())

G_DECLARE_INTERFACE(BaconExecutable, bacon_executable, BACON, EXECUTABLE, GObject)

/**
 * BaconExecutableInterface:
 * @parent_iface: the parent interface
 * @execute: runs the executable with the given arguments
 * @get_name: returns the canonical name of this executable
 * @get_description: returns a human-readable description
 *
 * The virtual function table for the #BaconExecutable interface.
 */
struct _BaconExecutableInterface
{
	GTypeInterface parent_iface;

	/* virtual methods */
	gint          (*execute)         (BaconExecutable  *self,
	                                  gint              argc,
	                                  gchar           **argv,
	                                  GError          **error);

	const gchar * (*get_name)        (BaconExecutable  *self);
	const gchar * (*get_description) (BaconExecutable  *self);
};

/**
 * bacon_executable_execute:
 * @self: a #BaconExecutable
 * @argc: argument count
 * @argv: (array length=argc): argument vector
 * @error: (nullable): return location for a #GError
 *
 * Runs the executable with the given arguments.
 *
 * Returns: the exit code (0 for success)
 */
gint
bacon_executable_execute(BaconExecutable  *self,
                         gint              argc,
                         gchar           **argv,
                         GError          **error);

/**
 * bacon_executable_get_name:
 * @self: a #BaconExecutable
 *
 * Returns the canonical name of this executable.
 *
 * Returns: (transfer none): the name string
 */
const gchar *
bacon_executable_get_name(BaconExecutable *self);

/**
 * bacon_executable_get_description:
 * @self: a #BaconExecutable
 *
 * Returns a human-readable description of this executable.
 *
 * Returns: (transfer none): the description string
 */
const gchar *
bacon_executable_get_description(BaconExecutable *self);

G_END_DECLS

#endif /* BACON_EXECUTABLE_H */
```

**Key patterns:**
- `G_DECLARE_INTERFACE(Type, type_func, NS, NAME, PrerequisiteType)` — the 5th argument is the prerequisite (usually `GObject`)
- `struct _BaconExecutableInterface` contains `GTypeInterface parent_iface` as its first member
- Virtual methods are function pointers in the struct
- Public wrappers are declared below the struct
- Padding (`gpointer _reserved[N]`) is optional but recommended for ABI stability

### 4. Generate Interface Source

```c
#define BACON_COMPILATION
#include "bacon-executable.h"

/**
 * SECTION:bacon-executable
 * @title: BaconExecutable
 * @short_description: Interface for anything that can be executed
 *
 * #BaconExecutable is a GInterface that defines the fundamental
 * contract for anything the shell can run.
 */

G_DEFINE_INTERFACE(BaconExecutable, bacon_executable, G_TYPE_OBJECT)

static void
bacon_executable_default_init(BaconExecutableInterface *iface)
{
	/* No default implementations or signals */
	(void)iface;
}

gint
bacon_executable_execute(BaconExecutable  *self,
                         gint              argc,
                         gchar           **argv,
                         GError          **error)
{
	BaconExecutableInterface *iface;

	g_return_val_if_fail(BACON_IS_EXECUTABLE(self), -1);
	g_return_val_if_fail(argc >= 0, -1);
	g_return_val_if_fail(error == NULL || *error == NULL, -1);

	iface = BACON_EXECUTABLE_GET_IFACE(self);
	g_return_val_if_fail(iface->execute != NULL, -1);

	return iface->execute(self, argc, argv, error);
}

const gchar *
bacon_executable_get_name(BaconExecutable *self)
{
	BaconExecutableInterface *iface;

	g_return_val_if_fail(BACON_IS_EXECUTABLE(self), NULL);

	iface = BACON_EXECUTABLE_GET_IFACE(self);
	g_return_val_if_fail(iface->get_name != NULL, NULL);

	return iface->get_name(self);
}

const gchar *
bacon_executable_get_description(BaconExecutable *self)
{
	BaconExecutableInterface *iface;

	g_return_val_if_fail(BACON_IS_EXECUTABLE(self), NULL);

	iface = BACON_EXECUTABLE_GET_IFACE(self);
	g_return_val_if_fail(iface->get_description != NULL, NULL);

	return iface->get_description(self);
}
```

**Key patterns:**
- `G_DEFINE_INTERFACE(Type, type_func, PrerequisiteGType)` — 3rd arg is the prerequisite GType
- `default_init` is called `{type_func}_default_init` and receives the interface pointer
- Wrapper functions use `{NS}_IS_{NAME}(self)` for type checking
- Wrapper functions use `{NS}_{NAME}_GET_IFACE(self)` to get the vtable
- Always check that the vfunc pointer is non-NULL before calling

### 5. Interface with Signals

When an interface defines signals, add them in `default_init`:

```c
enum {
	SIGNAL_MESSAGE_RECEIVED,
	SIGNAL_CONNECTION_CHANGED,
	N_SIGNALS
};

static guint channel_signals[N_SIGNALS] = { 0 };

static void
lc_channel_default_init(LcChannelInterface *iface)
{
	/**
	 * LcChannel::message-received:
	 * @self: the channel that received the message
	 * @msg: (type LcInboundMessage): the inbound message
	 *
	 * Emitted when a new message arrives on this channel.
	 */
	channel_signals[SIGNAL_MESSAGE_RECEIVED] =
		g_signal_new("message-received",
		              G_TYPE_FROM_INTERFACE(iface),
		              G_SIGNAL_RUN_LAST,
		              0,    /* class_offset */
		              NULL, /* accumulator */
		              NULL, /* accumulator data */
		              NULL, /* C marshaller (use generic) */
		              G_TYPE_NONE,
		              1,
		              LC_TYPE_INBOUND_MESSAGE);
}

G_DEFINE_INTERFACE(LcChannel, lc_channel, G_TYPE_OBJECT)
```

**Note:** When adding signals, `G_DEFINE_INTERFACE` must come AFTER the `default_init` function. GLib calls `default_init` as part of the interface's type class initialization.

### 6. Implementing the Interface in a Concrete Type

Show the user how to implement the interface in a concrete GObject:

```c
/* Forward declare the iface_init function */
static void my_type_executable_iface_init(BaconExecutableInterface *iface);

/* Use G_DEFINE_FINAL_TYPE_WITH_CODE for interface registration */
G_DEFINE_FINAL_TYPE_WITH_CODE(MyType, my_type, G_TYPE_OBJECT,
    G_IMPLEMENT_INTERFACE(BACON_TYPE_EXECUTABLE,
                          my_type_executable_iface_init))

/* Implement each virtual method */
static gint
my_type_execute(BaconExecutable  *executable,
                gint              argc,
                gchar           **argv,
                GError          **error)
{
	MyType *self;

	self = MY_TYPE(executable);
	/* ... implementation ... */
	return 0;
}

static const gchar *
my_type_get_name(BaconExecutable *executable)
{
	(void)executable;
	return "my-type";
}

static const gchar *
my_type_get_description(BaconExecutable *executable)
{
	(void)executable;
	return "Example implementation";
}

/* Wire up the vtable */
static void
my_type_executable_iface_init(BaconExecutableInterface *iface)
{
	iface->execute         = my_type_execute;
	iface->get_name        = my_type_get_name;
	iface->get_description = my_type_get_description;
}
```

**For derivable (abstract) types implementing interfaces:**

```c
G_DEFINE_ABSTRACT_TYPE_WITH_CODE(BaconCommand, bacon_command, G_TYPE_OBJECT,
    G_IMPLEMENT_INTERFACE(BACON_TYPE_EXECUTABLE,
                          bacon_command_executable_iface_init))
```

**For multiple interfaces:**

```c
G_DEFINE_FINAL_TYPE_WITH_CODE(MyType, my_type, G_TYPE_OBJECT,
    G_IMPLEMENT_INTERFACE(BACON_TYPE_EXECUTABLE,
                          my_type_executable_iface_init)
    G_IMPLEMENT_INTERFACE(BACON_TYPE_COMPLETABLE,
                          my_type_completable_iface_init))
```

### 7. Async Interface Pattern

For interfaces with async operations, use the GLib async pattern:

```c
struct _LcChannelInterface
{
	GTypeInterface parent_iface;

	void      (*connect_async)  (LcChannel           *self,
	                             GCancellable        *cancellable,
	                             GAsyncReadyCallback  cb,
	                             gpointer             data);
	gboolean  (*connect_finish) (LcChannel    *self,
	                             GAsyncResult *res,
	                             GError      **err);
};
```

Each async operation has an `_async` / `_finish` pair. The `_finish` function takes a `GAsyncResult` and returns the result or sets `GError`.

## Output Format

Two files per interface:

1. `{prefix}-{name}.h` — Interface declaration with vtable struct and public wrappers
2. `{prefix}-{name}.c` — Interface definition with `default_init` and wrapper implementations

Optionally, a third section showing how to implement the interface in a concrete type.

## Examples

**Input:** "Create a GInterface called GstBellHandler in the GST namespace with a single `handle_bell` virtual method that takes no arguments and returns void"

**Output:** `gst-bell-handler.h` + `gst-bell-handler.c` with:
- `G_DECLARE_INTERFACE(GstBellHandler, gst_bell_handler, GST, BELL_HANDLER, GObject)`
- Vtable with `void (*handle_bell)(GstBellHandler *self)`
- `gst_bell_handler_handle_bell()` public wrapper
- `G_DEFINE_INTERFACE` + empty `default_init`

## Constraints

- Never generate code that uses `//` comments
- Never use C99 variable declarations mid-block
- Never omit `g_return_val_if_fail` / `g_return_if_fail` preconditions in wrappers
- Never skip the NULL check on vfunc pointers in wrappers
- Never put `G_DEFINE_INTERFACE` before `default_init` in the source file
- Always use `G_TYPE_FROM_INTERFACE(iface)` (not `G_TYPE_FROM_CLASS`) for interface signals
