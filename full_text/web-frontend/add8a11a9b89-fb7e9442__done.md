# Done

Use at completion when the work exposed useful process feedback.

## Capture

- What changed.
- Quality gates run.
- Browser/design/API checks run.
- Residual risk or unverified scenarios.
- Any repeated friction that should become a rule, skill, script, or local note.
- Anything that should stay personal-only rather than being promoted to repo docs.

Keep it short and actionable.
