# chok-docs — 범용 문서 생성 스킬

사용자 콘텐츠를 입력받아 디자인 퀄리티 높은 HTML/PDF/PPTX 문서를 생성한다.
**Generate 전용** — 문서 동기화(sync)는 `chok-dev-agents/agents/chok-docs.md` 에이전트에 전담.

shared/ 프로토콜 비채택. 사유: 독립 문서 생성 스킬, 파이프라인 비직결.

## Step 1 — 의도 분류

사용자 입력에서 문서 유형과 출력 포맷을 추론. 모호하면 `AskUserQuestion`.

| 유형 | 키워드 신호 |
|------|-----------|
| `report` | 보고서, 리포트, 분석, report, analysis |
| `proposal` | 제안서, 기획서, proposal, plan |
| `presentation` | 프레젠테이션, 슬라이드, PPT, 발표 |
| `minimal` | 문서, 메모, 간단히, doc |

출력 포맷 추론: "PDF로" → pdf, "슬라이드" → pptx, "전부" → all, 미지정 → html 기본.

## Step 2 — 콘텐츠 수집

입력 소스 우선순위:
1. 사용자 직접 제공 텍스트/마크다운
2. 지정된 파일 경로 → `Read()`로 로드
3. `git diff` / `git log` 기반 변경 요약
4. 사용자에게 입력 요청 (`AskUserQuestion`)

**브랜드 토큰 로딩** — 토큰 스키마와 머지 절차를 읽고 적용하라: Read("~/.claude/skills/chok-docs/references/brand-tokens.md")

프리셋 데이터를 읽어라: Read("~/.claude/skills/chok-docs/presets.md")

토큰 로딩 순서:
1. `~/.claude/chok-docs/brand.json` 존재 확인 → `Bash: [ -f ~/.claude/chok-docs/brand.json ] && cat ~/.claude/chok-docs/brand.json`
2. 존재하면 프리셋 + 사용자 토큰 깊은 머지, 미존재면 프리셋만 사용
3. 프리셋 미지정 시 기본값 `corporate-light`

## Step 3 — HTML 생성

해당 유형의 HTML 구조를 읽고 적용하라: Read("~/.claude/skills/chok-docs/templates.md")

1. 해당 문서 유형(`report`/`proposal`/`presentation`/`minimal`) 템플릿 선택
2. **디자인 파운데이션** 섹션 CSS 전체를 `<style>` 최상단에 삽입 (토큰·타입스케일·elevation·모션·a11y·프린트)
3. 프리셋의 `:root` 오버라이드 블록(presets.md (B))을 파운데이션 뒤에 삽입 (corporate-light는 오버라이드 없음)
4. `:root` 변수에 머지된 최종 브랜드 토큰값 대입 (brand-tokens.md 매핑표)
5. **폰트 로딩** — 사용 폰트의 `<link>`(+ preconnect)를 `<head>`에 삽입 (Pretendard/Noto Serif KR/Montserrat). 웹폰트 = 퀄리티 최대 레버, 생략 금지
6. `{{PLACEHOLDER}}`를 실제 콘텐츠로 치환 (lorem ipsum 금지, 실제 콘텐츠만)
7. 시맨틱 HTML5 구조 유지. 라벨은 `.u-eyebrow`, 리드문은 `.u-lead`, 강조박스는 `.callout`, 지표는 `.metric`(proposal 한정) 유틸 활용
8. **넓은 `<table>`은 `<div class="table-wrap">`로 감싼다** — 375px에서 페이지 전체가 아닌 표만 좌우 스크롤 (반응형 필수)

출력 경로 결정:
- 사용자 지정 경로 있으면 사용
- 없으면 `./chok-docs-output/{type}-{YYYYMMDD-HHmm}.html`
- 디렉토리 없으면 `Bash: mkdir -p ./chok-docs-output`

→ `Write()`로 .html 파일 생성.

## Step 4 — 포맷 변환

변환 엔진 로직을 읽고 실행하라: Read("~/.claude/skills/chok-docs/references/renderers.md")

사용자가 요청한 포맷에 따라:
- `pdf` → PDF 변환 (renderers.md의 3단계 체인)
- `pptx` → PPTX 변환 (renderers.md의 2단계 체인)
- `all` → PDF + PPTX 모두 시도
- `html` → 추가 변환 없음

엔진 미가용 시 경고 메시지 출력 후 계속 진행 (크래시 금지).

## Step 5 — 프리뷰 + 피드백 루프

```
LOOP (최대 5회):
  1. HTML을 브라우저에서 열기
     Bash: open <html_path>    (macOS)

  2. AskUserQuestion:
     "문서가 브라우저에 열렸습니다. 수정할 부분이 있나요?
      'done'이라고 하시면 최종 출력합니다."

  3. "done" / "완료" / "좋아" → 루프 종료, Step 6으로

  4. 피드백 → Edit()으로 HTML surgical 수정 (전체 재생성 아님)

  5. 요청된 포맷만 재변환 (Step 4 재실행)
```

## Step 6 — 최종 출력

출력 스키마를 읽고 형식에 맞춰 결과를 보고하라: Read("~/.claude/skills/chok-docs/references/output-schema.md")

산출물 경로 + 메타데이터 JSON을 사용자에게 출력.
후속 핸드오프 없음. 문서 생성은 최종 산출물.
