# Handoff

Use when work must continue later or with another agent.

## Include

- Goal and current status.
- Branch name and changed files.
- Important repo conventions learned.
- Commands already run and their outcomes.
- Active errors or blockers.
- Remaining next steps.
- Relevant ticket/design links without secrets.
- Any casino-policy facts still unknown.

Exclude tokens, auth state, private transcripts, and unrelated workplace context.
