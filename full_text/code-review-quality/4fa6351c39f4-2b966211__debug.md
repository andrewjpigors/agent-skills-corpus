Help debug the issue using a systematic, hypothesis-driven approach:

## 1. Problem Definition
- What is the expected behavior?
- What is the actual behavior?
- When did it start happening?
- Is it reproducible? Under what conditions?

## 2. Information Gathering
- Exact error message and stack trace
- Error location (file:line)
- Relevant log output
- Input data that triggers the issue
- Recent changes to the code

## 3. Hypothesis Formation

Form hypotheses ranked by likelihood:
- Hypothesis 1: [Most likely cause]
  - Evidence for/against
  - Test to verify

## 4. Systematic Testing

For each hypothesis:
1. Design a minimal test case
2. Add targeted logging/instrumentation
3. Execute and observe
4. Confirm or eliminate hypothesis

## 5. Root Cause Analysis

Once found, document:
- The actual root cause
- Why the bug occurred (not just what)
- Why it wasn't caught earlier

## 6. Fix Verification

- Fix addresses root cause, not just symptoms
- Regression test added
- No new issues introduced
- Related code checked for similar issues
