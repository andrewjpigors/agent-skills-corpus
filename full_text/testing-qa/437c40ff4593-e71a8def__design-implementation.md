# Design Implementation

Use after policy-approved design access is available.

## Workflow

1. Read design node and existing nearby UI.
2. Identify reusable components, tokens, typography, layout, breakpoints, states,
   and assets.
3. Implement the real screen/component, not a marketing placeholder.
4. Cover loading, error, empty, disabled, hover/focus, and responsive states.
5. Use browser QA and `design-fidelity-reviewer` before completion.

Do not invent missing design states. Flag gaps.
