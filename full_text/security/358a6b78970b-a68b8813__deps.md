name: deps
description: Dependency audit for security, outdated, unused, and licenses
---

Perform a dependency audit of the project. Follow this process:

## 1. Detect Package Manager

Identify the project's dependency management:
- **Python**: `pyproject.toml`, `requirements.txt`, `setup.py`, `Pipfile`, `poetry.lock`
- **Node.js**: `package.json`, `package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`
- **Rust**: `Cargo.toml`, `Cargo.lock`
- **Go**: `go.mod`, `go.sum`

Read the dependency files and lock files.

## 2. Security Vulnerabilities

Check for known vulnerabilities:

**Python:**
```bash
uv run pip-audit
uv run safety check
```

**Node.js:**
```bash
npm audit
yarn audit
```

If tools aren't available, check dependency versions against known CVE databases and report findings.

## 3. Outdated Dependencies

Check for outdated packages and categorize updates:
- **Patch** (1.2.3 -> 1.2.4): Bug fixes, safe to update
- **Minor** (1.2.3 -> 1.3.0): New features, usually safe
- **Major** (1.2.3 -> 2.0.0): Breaking changes, review needed

## 4. Unused Dependencies

Identify dependencies that appear to be unused:
- Search the codebase for imports of each dependency
- Flag dependencies with zero import references

## 5. License Compliance

Check licenses of all dependencies:
- Permissive (MIT, Apache-2.0, BSD): Generally safe
- Copyleft (GPL, AGPL): May have implications for proprietary code
- Unknown: Flag for review
