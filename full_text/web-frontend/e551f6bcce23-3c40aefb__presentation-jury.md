# `presentation-jury` : préparer son oral

## Vue d'ensemble

L'oral compte autant que la planche. Beaucoup de très bons projets sont sous-évalués parce que mal défendus. Ce skill aide à structurer.

## Durée typique en L1

- Présentation : **5 à 10 minutes**.
- Questions du jury : **5 à 15 minutes**.
- Bilan : **3 à 5 minutes** par le jury.

## Structure recommandée

### 1. Accroche (30 secondes)
Une phrase qui donne **l'intention principale**. "Mon projet est une maison qui s'enroule autour d'un arbre existant pour préserver le vide."

### 2. Le contexte (1 minute)
Très bref, le jury connaît le sujet. Rappeler :
- où est le site,
- la contrainte principale,
- le programme.

### 3. Le parti pris (1 minute)
La **décision majeure** qui a structuré tout le projet. Une seule.

### 4. Démonstration (3 à 6 minutes)
Parcourir le projet via les dessins, pas dans l'ordre des planches mais dans l'ordre du **raisonnement**.

Exemple :
1. Plan masse (implantation choisie et pourquoi)
2. Plan RDC (organisation, parcours)
3. Plan R+1 (et différences)
4. Coupe (rapport au site, hauteurs, lumière)
5. Élévation (matérialité, expression)
6. Détail clé (matériau, assemblage, structure)

### 5. Conclusion (30 secondes)
Revenir à l'intention initiale : "C'est ainsi que mon projet répond à...". Pas de "voilà j'ai fini" : finir sur une phrase forte.

## Anticiper les questions

Le jury va probablement demander :
- **"Pourquoi cette implantation ?"** : préparer 2-3 raisons.
- **"Comment ça tient ?"** : avoir étudié la structure même si on ne la dessine pas en détail.
- **"D'où vient la lumière ?"** : connaître les orientations.
- **"Et l'accessibilité PMR ?"** : si rampe, escalier, niveaux différents.
- **"Quel matériau ?"** : avoir une réponse argumentée, pas "ça serait joli".
- **"Quelle référence ?"** : citer 1-2 projets qui ont nourri ta réflexion.

## Conseils

- **Ne pas lire** : avoir des notes mais regarder le jury.
- **Pointer les dessins** : usiner sa main, indiquer précisément. Pas "ici", mais "au niveau du seuil de l'entrée".
- **Vocabulaire** : utiliser les bons mots (parti, programme, gabarit, recul, mitoyen...). Voir le skill `lexique-archi-fr`.
- **Respirer** : pas de débit nerveux.
- **Pas de dénigrement** : "j'ai pas eu le temps de finir le détail" est interdit, le jury le voit.
- **Critique constructive** : si le jury identifie un défaut, ne pas se défendre frontalement. "Vous avez raison, c'est un point que je travaillerais en priorité."

## Procédure

1. **Demander le contexte** : durée, type de jury (interne, externe), sujet.
2. **Aider à structurer** : trouver l'accroche, le parti, le fil narratif.
3. **Préparer 5 questions probables** et leurs réponses.
4. **Conseiller sur la posture** : où se placer, comment pointer.

## Sortie attendue

```
Plan de présentation, 7 minutes

00:00 - Accroche
"Mon projet inverse le rapport classique entre intérieur et jardin :
le jardin entre dans la maison par une faille traversante."

00:30 - Contexte
Site à Wambrechies, parcelle nord-sud de 400 m², arbre existant au centre,
maison voisine collée au mur ouest, ouverture au sud sur la Marque.

01:30 - Parti
Préserver l'arbre. Le projet est tordu autour de lui.

02:30 - Démonstration
- plan masse : implantation en L autour de l'arbre
- plan RDC : pièces de jour ouvertes sur le sud, cuisine pivot
- plan R+1 : chambres tournées vers l'arbre
- coupe : double hauteur dans le séjour, vue plongeante sur l'arbre
- élévation sud : grande baie, bardage bois vertical
- détail : caisson menuiserie acier qui cadre la vue arbre

06:00 - Conclusion
"La maison fait corps avec son arbre, le projet sera réussi quand
on ne saura plus dire qui des deux a été là avant."

Questions probables
1. "Pourquoi en L et pas en T ?" -> permet de garder mitoyenneté ouest libre
2. "Comment l'arbre vit-il avec la maison ?" -> distance racines > 4 m
3. "Et l'hiver, sans feuilles ?" -> vue dégagée vers la Marque devient l'atout
```

## Notes pédagogiques

- **S'entraîner à voix haute** au moins 3 fois avant l'oral.
- **Filmer** sa présentation : on voit ses tics.
- **Faire écouter** une amie qui n'a pas vu le projet : si elle comprend, c'est gagné.

## Limites

- Le skill ne te débarrasse pas du stress, il structure.
- Les jurys ont des cultures variées (Beaux-Arts, structuralistes, écologistes) : adapter le vocabulaire.
