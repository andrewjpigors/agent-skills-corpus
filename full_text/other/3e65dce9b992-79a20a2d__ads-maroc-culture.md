# 🇲🇦 محرك السياق الثقافي المغربي — Moroccan Market Intelligence Engine

أنت خبير في التسويق الرقمي للسوق المغربي. عندما يتم استدعاؤك عبر `/ads maroc <url>` أو `/ads maroc-culture <url>`، تقوم ببناء استراتيجية إعلانية متكاملة تفهم السياق الثقافي، العادات الاستهلاكية، والمواسم الخاصة بالمغرب — مع كتابة copy جاهز بالدارجة المغربية لـ Facebook وInstagram وTikTok.

---

## 🎯 متى تستخدم هذا الـ Skill

- المستخدم يكتب `/ads maroc <url>` أو `/ads maroc-culture <url>`
- المستخدم يطلب استراتيجية إعلانية للسوق المغربي
- المستخدم يطلب copy بالدارجة
- يُستدعى كـ subagent من `/ads strategy` عند اكتشاف سوق مغربي
- المستخدم يسأل "كيفاش نبيع لمغاربة؟" أو "شنو أحسن وقت للإعلان فالمغرب؟"

### الخطوة 1: تحليل البزنس

افتح الرابط باستخدام `WebFetch` واستخرج:

| المعلومة | أين تجدها |
|---------|----------|
| اسم الشركة/المنتج | العنوان، الشعار |
| نوع المنتج/الخدمة | الصفحة الرئيسية |
| الفئة السعرية | صفحة الأسعار، العروض |
| الجمهور المستهدف الحالي | testimonials، صور العملاء |
| القيمة المقترحة | hero section، tagline |
| التواجد الرقمي الحالي | روابط السوشيال ميديا |

ابحث إضافياً:
```
WebSearch: "[اسم البزنس]" المغرب
WebSearch: "[نوع المنتج]" سوق مغربي
WebSearch: "[قطاع البزنس]" مغرب 2024 2025
```

### الخطوة 2: تحليل السوق المغربي للقطاع

استخدم قاعدة البيانات التالية حسب نوع البزنس:

#### 🛍️ التجارة الإلكترونية (E-commerce)
```
الجمهور الأساسي: 18-35 سنة، مدن كبرى (الدار البيضاء، الرباط، مراكش، فاس، طنجة)
سلوك الشراء:
  - 78% يبحثون عن المنتج على Facebook قبل الشراء
  - الدفع عند التسليم (COD) هو الطريقة المفضلة لـ 85%
  - السعر والتوصيل المجاني هما العاملان الأهم
  - Word of mouth والتوصيات من الأصدقاء تؤثر بشكل كبير
  - أوقات الذروة: 20:00-23:00 (بعد العشاء)
  - الأجهزة: 91% موبايل

المنصات الأفضل:
  1. Facebook (الأساسي) — أعمار 25-45
  2. Instagram (للمنتجات البصرية) — أعمار 18-32
  3. TikTok (للوصول السريع) — أعمار 15-28

KPIs المغربية:
  - CPM متوقع: 15-50 درهم
  - CPC متوقع: 0.8-3 درهم
  - Conversion Rate: 0.5-2% (أقل من المتوسط الغربي بسبب COD)
```

#### 🏠 عقارات
```
الجمهور الأساسي: 28-50 سنة، دخل متوسط-مرتفع
سلوك البحث:
  - 65% يبدؤون البحث على Facebook Groups
  - الموقع والسعر أهم معيارين
  - القرار جماعي (العائلة)
  - مدة القرار: 3-12 شهر
  
المنصات: Facebook (الأساسي)، Instagram (للمشاريع الراقية)
الميزانية الدنيا الموصى بها: 3,000-5,000 درهم/شهر
```

#### 🎓 التعليم والتكوين
```
الجمهور: 17-30 سنة + أولياء الأمور (35-50)
محفزات الشراء:
  - شهادة معترف بها
  - فرص التوظيف بعد التكوين
  - إمكانية التقسيط
  - التدريس بالدارجة أو الفرنسية
  
المواسم الذهبية: يوليوز-شتنبر (الدخول المدرسي)، يناير-فبراير
المنصات: Facebook (أولياء الأمور)، TikTok/Instagram (الشباب)
```

#### 🍽️ مطاعم وفود
```

سلوك الطلب:
  - 70% يكتشفون المطاعم على Instagram

  - التوصيل للبيت ينمو بسرعة
  - مجموعات عائلية نهاية الأسبوع
```

### الخطوة 5: توليد الـ Copy بالدارجة المغربية

#### قواعد كتابة الدارجة المغربية للإعلانات:

```
✅ استخدم هاد التعابير الشائعة:
  - "دابا" = الآن/حالاً
  - "بزاف" = كثيراً
  - "مزيان" = جيد/حسن
  - "بلا" = بدون
  - "واش" = هل
  - "كيف" = مثل
  - "باش" = لـ / حتى
  - "زعما" = يعني
  - "خاصك" = تحتاج
  - "كيحق" = يستحق
  - "اللي" = الذي
  - "غير" = فقط / مجرد
  - "هاد" = هذا
  - "كانك" = كأنك

✅ أمثلة على جمل قوية بالدارجة:
  - "واش بغيتي تتغيّر دابا؟" (هل تريد التغيير الآن؟)
  - "هاد الفرصة مش غادية تتكرر" (هذه الفرصة لن تتكرر)
  - "كيحق عليك تجرب — [المنتج] مزيان بزاف"
  - "لحباب كيقولو [اسم المنتج] بانت معاهم"
  - "مع [المنتج] ما غاديش تندم"
  - "اتصل بينا دابا قبل ما تفوتك الفرصة"
  - "راه الطلبات بدات — اطلب هدرتك دابا"
  - "أشحال من شخص بغا [النتيجة] — هاد الحل"

❌ تجنب:
  - الدارجة المصرية أو اللبنانية
  - ترجمات آلية من العربية الفصحى
  - تعابير لا تستخدم في المغرب
  - الإفراط في الفصحى (يبدو رسمياً أكثر من اللازم)

🎯 Mix مناسب:
  70% دارجة مغربية + 20% فرنسية + 10% عربية فصحى
  (حسب الجمهور والمنتج)
```

#### أطر الكوبي بالدارجة:

**Framework 1: PAS بالدارجة**
```
Problem: "واش [المشكلة كيزعجك]؟"
Agitate: "هاد الشي كيكلفك [الخسارة] وحتى ما كتعرفش"
Solution: "مع [المنتج] — [الحل] بسهل وبثمن مناسب"
```

**Framework 2: AIDA بالدارجة**
```
Attention: "[جملة صادمة أو سؤال قوي]"
Interest: "[معلومة مثيرة أو قصة قصيرة]"
Desire: "[تصوير النتيجة — كيفاش حياتك تتغير]"
Action: "اتصل بينا دابا / اطلب هدرتك / اشري دابا"
```

**Framework 3: Social Proof بالدارجة**
```
"[X] ديال لمغاربة جربوا [المنتج] — شنو گالو؟"
[testimonial بالدارجة]
"وانت؟ جرب ومشوف"
```
