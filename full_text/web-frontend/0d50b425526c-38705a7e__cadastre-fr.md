# `cadastre-fr` : identifier une parcelle cadastrale

## Vue d'ensemble

Le **cadastre** recense toutes les parcelles de France avec leur géométrie, leur surface, leur numéro. C'est le point de départ de toute analyse de site sérieuse.

Ce skill aide à :
- retrouver une parcelle à partir d'une adresse,
- lire la **référence cadastrale** (commune, section, numéro),
- estimer la **surface**, les **dimensions**, le **voisinage immédiat**.

## Entrées attendues

- adresse précise, ou
- coordonnées GPS, ou
- référence cadastrale directe (ex: "Lille AB 0123").

## Sources officielles

- **cadastre.gouv.fr** : https://www.cadastre.gouv.fr/
  consultation des plans, extraits cadastraux
- **Géoportail** (couche cadastre) : https://www.geoportail.gouv.fr/
  vue cartographique pratique, superposition avec orthophotos
- **API Carto IGN** pour les usages programmatiques : https://apicarto.ign.fr/

## Référence cadastrale française

Format : `[commune] [section] [numéro]`. Exemple : `59350 (Lille) AB 0123`.

- **commune** : code INSEE à 5 chiffres
- **section** : 1 ou 2 lettres (AA, AB, ... ZZ)
- **numéro** : numéro de parcelle dans la section

## Procédure

1. **Géolocaliser l'adresse** (BAN, base adresse nationale).
2. **Ouvrir cadastre.gouv.fr** sur les coordonnées.
3. **Identifier la parcelle** : noter référence, surface, dimensions principales (largeur sur rue, profondeur).
4. **Observer le voisinage** : parcelles mitoyennes, accès, alignement bâti.
5. **Récupérer un extrait** si l'utilisateur en a besoin pour son dossier (impression PDF gratuite).

## Sortie attendue

```
Parcelle : Lille (59350) section AB n°0123
Surface : 412 m²
Forme : trapézoïdale, 12 m sur rue, profondeur 35 m
Voisinage :
  - nord : parcelle AB 0122, bâti R+3
  - sud : parcelle AB 0124, jardin
  - est : rue de Paris
  - ouest : limite de fond, parcelle AB 0118
Accès : 1 entrée sur rue de Paris
```

## Notes pédagogiques

- Le cadastre n'a pas valeur juridique sur les limites de propriété (c'est le bornage qui fait foi), mais il est suffisant pour une analyse de site étudiante.
- La **surface cadastrale** peut différer un peu de la surface réelle mesurée sur le terrain.
- Une parcelle peut être divisée plus tard (division parcellaire) ou regroupée.

## Limites

- Certaines parcelles très récentes peuvent ne pas être encore en ligne.
- Les bâtiments représentés sur le plan cadastral ne sont pas toujours à jour.
