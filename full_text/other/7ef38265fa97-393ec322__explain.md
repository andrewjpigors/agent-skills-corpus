Explain the provided code for onboarding and understanding. Follow this process:

## 1. Read and Identify

- Read the target file(s) completely
- Identify the programming language and framework
- Note imports, dependencies, and external integrations
- Find related files (tests, configs, types)

## 2. Three-Level Explanation

Provide explanations at three levels of detail:

### One-Line Summary
A single sentence describing what this code does and why it exists.

### Paragraph Overview
3-5 sentences covering:
- Primary purpose and responsibility
- Key inputs and outputs
- Where it fits in the larger system
- Important design decisions

### Detailed Walkthrough
Section-by-section explanation covering:
- Each public function/class and its contract
- Data flow through the module
- Error handling strategy
- Side effects and state mutations
- Performance characteristics (if relevant)

## 3. Dependency Map

Show what this code depends on and what depends on it:

```
[upstream deps] --> [THIS MODULE] --> [downstream consumers]
```

List:
- External libraries used and why
- Internal modules imported
- Who calls this code (search for imports/references)

## 4. Key Patterns

Identify and explain any design patterns used:
- Architectural patterns (MVC, repository, service layer)
- Language idioms (context managers, decorators, hooks)
- Project-specific conventions

## 5. Suggested Reading Order

If the user is new to this area, suggest an order to read related files:
1. Start with [file] - because [reason]
2. Then read [file] - because [reason]
3. Finally [file] - because [reason]
