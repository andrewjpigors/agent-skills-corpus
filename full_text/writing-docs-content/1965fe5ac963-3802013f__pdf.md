# PDF

Use this skill to generate `.pdf` files locally.

## Setup

```bash
python3 -m pip install --break-system-packages -r "${PI_CODING_AGENT_DIR:-${HOME}/.pi/agent}/skills/pdf/requirements.txt"
```

## Start here

1. Write a JSON spec.
2. Run `scripts/pdf_tool.py create spec.json output.pdf`.
3. Prefer editing source content and regenerating the PDF instead of trying to patch an existing PDF.

## Command

```bash
python3 agent/skills/pdf/scripts/pdf_tool.py create spec.json output.pdf
```

## Recommended workflow

- Use structured `content` blocks for predictable output.
- If the user already has markdown, put it in the `markdown` field instead.
- Keep images explicit with `path` or `url`.
- For revisions, update the spec and regenerate.

## Supported block types

- `title`
- `subtitle`
- `heading`
- `paragraph`
- `list`
- `code`
- `image`
