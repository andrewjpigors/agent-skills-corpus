Generate documentation for the provided code. Follow this process:

## 1. Detect Documentation Type

Determine what documentation is needed:
- **Docstrings**: Missing or incomplete function/class documentation
- **README**: Module or project overview
- **API Reference**: Endpoint documentation
- **Inline comments**: Complex logic that needs explanation

If not specified, default to docstrings for code files and README for directories.

## 2. Analyze Public Interface

Read the code and identify:
- All public functions, classes, and methods
- Parameters, return types, and exceptions
- Side effects and preconditions
- Usage patterns from tests or callers

## 3. Match Project Style

Detect and follow the existing documentation style:

**Python:**
- Google style: `Args:`, `Returns:`, `Raises:` sections
- NumPy style: `Parameters`, `Returns`, `Raises` with dashes
- Sphinx style: `:param name:`, `:returns:`, `:raises:`
- If no existing style, default to Google style

**TypeScript/JavaScript:**
- TSDoc/JSDoc: `@param`, `@returns`, `@throws`
- Follow existing patterns in the codebase

**README:**
- Match existing README structure if one exists
- Default: Description, Installation, Usage, API, Examples

## 4. Generate Documentation

For each public interface, write:
- One-line summary (what it does)
- Extended description (when needed for complex behavior)
- All parameters with types and descriptions
- Return value description
- Exceptions/errors that can be raised
- Usage example (for non-obvious interfaces)

Rules:
- Be precise - document actual behavior, not aspirational behavior
- Include edge cases and gotchas in descriptions
- Reference related functions when relevant
- Don't document private/internal functions unless explicitly asked

## 5. Output

Present the documentation in one of these formats:
- **Inline**: Show the documented code (for docstrings)
- **Standalone**: Separate markdown file (for README/API docs)
- **Diff**: Show only additions (for large files)

State which files were documented and any public interfaces that were unclear.
